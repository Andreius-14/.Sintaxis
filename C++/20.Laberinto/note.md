## Archivos

1. Archivos cpp
2. Archivos .h

## Compilacion

- bastara con copilar todos los archivos .cpp

## Workflow

- tenemos el archivo main.cpp
- tenemos el archivos name.h
  - archivos header
  - ejemplo ==> moustruo.h moustruo.cpp

  - moustruo.h (plantilla)
  - moustruo.cpp (implementacion)

  - Es para crear Clases
  - primera linea de name.h (evita redundancia)

  ```h
  //moderno
  # pragma once

  /*<Tu codigo>*/

  ```

  ```h
  //tradicional
  #ifndef NAMEFILE_H
  #define MAPCELL_H

  /*<Tu codigo>*/

  #endif
  ```

- se importa con la ruta name.h
